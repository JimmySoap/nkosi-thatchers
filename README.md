South Africa. Plain HTML + CSS + a little vanilla JS. No build step, no
framework, no npm required to run it.

## 2. Paste your Formspree ID  ← do this to make the form work

The contact form posts to [Formspree](https://formspree.io). Until your ID is
in, the form shows a friendly "not connected yet — call us" message instead of
pretending to send.

1. Sign up at https://formspree.io (free plan is fine) and create a form.
2. Formspree gives you an endpoint like `https://formspree.io/f/abcdwxyz`.
3. Open **`index.html`**, find this line (there's a big comment block above it):

   ```html
   <form id="quote-form" class="quote-form"
         action="https://formspree.io/f/YOUR_FORM_ID" method="POST" novalidate>
   ```

4. Replace **`YOUR_FORM_ID`** with your ID, e.g.
   `action="https://formspree.io/f/abcdwxyz"`.
5. Save, redeploy. Submit a test — the first submission asks you to confirm the
   form by email (Formspree's one-time verification).

Nothing else needs touching: validation, the spam honeypot, and the "thanks,
we'll be in touch" success message all work once the ID is in.

## 3. Add or change gallery photos

Originals live in **`images/originals/`**. The web-sized versions
(WebP + JPEG at 400 / 800 / 1600 wide) are generated into **`images/`** by a
small Python script.

To add a photo:

1. Drop the full-size photo into `images/originals/`.
2. Open **`build_images.py`** and add a line to the `IMAGES` dict:

   ```python
   "my-new-roof": "the-original-filename.jpg",
   ```

   The key (`my-new-roof`) becomes the filename slug.
3. Regenerate the optimised images:

   ```bash
   py build_images.py
   ```

   (Needs Pillow: `py -m pip install pillow` — already installed here.)
   It never upscales past a photo's real size.
4. Add a gallery tile in `index.html` — copy an existing
   `<a class="gallery-item">…</a>` block and swap the `slug`, the
   `width`/`height`, and **write real alt text** describing the photo.

To remove a photo, delete its `<a class="gallery-item">` block (and optionally
its line in `build_images.py` + the generated files).

The `og-image.jpg` (social-share preview, 1200×630) is also generated by the
snippet at the bottom of the image step — regenerate it if you change the hero.

## 4. Deploy to GitHub Pages + point the domain

### a. Push to GitHub

```bash
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin master
```

### b. Turn on Pages

1. GitHub repo → **Settings → Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** `master`, folder `/ (root)` → **Save**.
4. The `CNAME` file in this repo already contains `www.nkosi-thatchers.co.za`,
   so Pages will pick up the custom domain automatically. If the "Custom
   domain" box is empty, type `www.nkosi-thatchers.co.za` and Save.

### c. DNS (at your domain registrar — where nkosi-thatchers.co.za is registered)

You're using the **www** subdomain, so add a **CNAME record**:

| Type  | Host / Name | Value                       |
|-------|-------------|-----------------------------|
| CNAME | `www`       | `<you>.github.io`           |

(Replace `<you>` with your GitHub username. Note: the value is your
`username.github.io`, **not** the repo name.)

Also point the bare domain (`nkosi-thatchers.co.za`) at GitHub so people who
leave off the `www` still land on the site. Add these **A records** for the
apex/root (`@`):

| Type | Host | Value           |
|------|------|-----------------|
| A    | `@`  | 185.199.108.153 |
| A    | `@`  | 185.199.109.153 |
| A    | `@`  | 185.199.110.153 |
| A    | `@`  | 185.199.111.153 |

Some registrars call the root host `@`, some leave it blank — same thing.

### d. Enforce HTTPS

DNS can take anywhere from a few minutes to a few hours. Once GitHub shows the
domain as verified, tick **Settings → Pages → Enforce HTTPS**. Done.

## 5. Structure

```
index.html          the whole site (single page, anchor nav)
css/styles.css       all styles (mobile-first)
js/main.js           lightbox, scroll-reveal, form validation/submit
fonts/               self-hosted Bitter (headings) — no font CDN
images/              generated WebP + JPEG (400/800/1600) + og-image
images/originals/    your untouched source photos
build_images.py      regenerates images/ from images/originals/
favicon.svg .ico, apple-touch-icon.png, robots.txt, sitemap.xml, CNAME
```
